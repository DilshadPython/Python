## What is Encapsulation?
Encapsulation is the bundling of data and the methods that operate on that data into a single unit (class), while restricting direct access to some of the object's components.

## What are the built-in types that Python provides?

### Mutable Types:
#### 1. List `[]`
#### 2. Set `set([])`
#### 3. Dictionary `{}`

### Immutable Types:
#### 1. Tuple `()`
#### 2. String `""`
#### 3. Numbers (`int`, `float`, `complex`)

### What is lambda?
A lambda is a single-expression anonymous function defined using the `lambda` keyword and used inline.

### Why do Python lambda forms not contain statements?
Because lambdas are designed to evaluate a single expression and return the result at runtime, rather than executing multi-line statements.

### What are Iterators?
Iterators are objects that implement the iterator protocol (`__iter__()` and `__next__()`) to traverse elements of a container object like a List, Tuple, or Dictionary.

### What is slicing?
Slicing is a mechanism to select a subset or range of items from sequence types like lists, tuples, and strings using standard syntax `sequence[start:stop:step]`.

### What is the difference between `xrange` and `range`?
In Python 2, `xrange()` returned a generator-like object evaluating lazily, while `range()` returned a full list in memory. In Python 3, `range()` behaves like Python 2's `xrange()`, returning a memory-efficient sequence object, and `xrange()` was removed.

### What are Python decorators?
A Python decorator is a design pattern used to extend or modify the behavior of a function or method dynamically without permanently modifying its code.

### What is pickling and unpickling?
The `pickle` module accepts any Python object, serializes it into a byte stream, and saves it to a file using the `dump()` function (pickling). Retrieving original Python objects from the stored byte stream is called unpickling (`load()`).

### What are generators in Python?
Generators are simple and powerful tools for creating iterators. They are written like regular functions but use the `yield` statement whenever they return data.

### Division Behavior: Python 2 vs Python 3

#### Python 2.7 Division (Integer Truncation):
```text
Python 2.7.15+ (default, Jul  9 2019, 16:51:35) 
[GCC 7.4.0] on linux2
>>> 9 / 2
4
```

#### Python 3 Division (Always Returns Float):
```text
Python 3.12 (default)
>>> 9 / 2
4.5
>>> 12 / 3
4.0
>>> 12 // 3
4
```

### Input Function Behavior: Python 2 vs Python 3
- In Python 2, `raw_input()` returned a string, whereas `input()` evaluated the input string as Python code.
- In Python 3, `input()` always returns a string, and `raw_input()` was removed.
