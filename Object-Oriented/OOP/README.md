# OOP Module

Welcome to the **OOP Module**, demonstrating fundamental class structures, pet hierarchies, vehicle models, and 2D vector point math.

---

## Directory Structure & Module Catalog

```text
OOP/
├── README.md                   # Documentation and execution guide
├── pet_hierarchy.py            # Dog & Cat pet class inheritance
├── vehicle_hierarchy.py        # Vehicle base class & Car/Van subclasses
├── point_geometry.py           # 2D Point vector arithmetic & operator overloading
├── test_oop.py                 # Unit test suite
└── [legacy wrappers]           # Refactored entry points (first_class.py, etc.)
```

---

## How to Run

```bash
# Run pet hierarchy demonstration
python3 pet_hierarchy.py

# Run vehicle hierarchy demonstration
python3 vehicle_hierarchy.py

# Run point geometry demonstration
python3 point_geometry.py

# Run unit tests
python3 -m unittest test_oop.py
```
