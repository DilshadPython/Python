# Classes Module

Welcome to the **Classes Module**, demonstrating basic class attributes, instance initialization, and inventory counter management.

---

## Directory Structure & Module Catalog

```text
classes/
├── README.md                   # Documentation and execution guide
├── user_account.py             # User account name formatting
├── car_inventory.py            # Car inventory with class-level attributes & counters
├── test_classes.py             # Unit test suite
└── [legacy wrappers]           # Refactored entry points (account.py, automobiles.py, etc.)
```

---

## How to Run

```bash
# Run user account demonstration
python3 user_account.py

# Run car inventory demonstration
python3 car_inventory.py

# Run unit tests
python3 -m unittest test_classes.py
```
