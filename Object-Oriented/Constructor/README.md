# Constructor Module

Welcome to the **Constructor Module**, demonstrating class initialization mechanics (`__init__`), default parameter values, and defensive type validation.

---

## Directory Structure & Module Catalog

```text
Constructor/
├── README.md                   # Documentation and execution guide
├── animal_sounds.py            # Animal constructor and sound emission
├── number_counter.py           # Parameterized/default constructors & type validation
├── test_constructor.py         # Unit test suite
└── [legacy wrappers]           # Refactored entry points (animal.py, first_constructor.py, etc.)
```

---

## How to Run

```bash
# Run animal sounds demonstration
python3 animal_sounds.py

# Run number counter constructor demonstration
python3 number_counter.py

# Run unit tests
python3 -m unittest test_constructor.py
```
